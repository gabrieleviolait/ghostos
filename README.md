# GhostOS

Versione corrente: v0.8

Ghost OS e' un piccolo sistema operativo educativo in Assembly NASM
16-bit real mode. Il kernel e' diviso in moduli `.inc`, la shell include
una calcolatrice multi-digit, terminale VGA con scrolling, dashboard TUI,
lettura FAT12 read-only, pagine `.GHT` da disco e una demo protected mode.
